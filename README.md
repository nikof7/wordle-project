# Wordle Programación

Este proyecto es una versión del juego **Wordle**, pero las palabras a adivinar están relacionadas con el **desarrollo web**.

## Características

* Juego interactivo para adivinar palabras relacionadas con el desarrollo web.
* Feedback visual con colores (verde, amarillo, gris).

## Cómo Jugar

1. Escribe una palabra relacionada con el desarrollo web en las casillas.
2. Recibe pistas sobre si las letras son correctas.
3. Intenta adivinar la palabra en los intentos disponibles.

## Tecnologías

* **HTML5**, **CSS3**, **JavaScript**

## Instalación

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador y comienza a jugar.
